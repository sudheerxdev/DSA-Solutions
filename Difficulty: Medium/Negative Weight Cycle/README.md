<h2><a href="https://www.geeksforgeeks.org/problems/negative-weight-cycle3504/1">Negative Weight Cycle</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a weighted directed graph containing <strong>V</strong> vertices numbered from 0 to V - 1 and a list of <strong>E</strong> directed edges <strong>edges[][]</strong>, determine whether the graph contains a negative weight cycle or not. </span></p>
<p><span style="font-size: 18px;">Each edge is represented as: </span><span style="font-size: 18px;">[</span><span style="font-size: 18px;">u, v, w], </span><span style="font-size: 18px;">where there is a directed edge from vertex u to vertex v having the given weight w.</span></p>
<p><span style="font-size: 18px;"><strong>Note: </strong>A negative-weight cycle is a cycle in a graph whose edges sum to a negative value.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>V = 4, E = 4, edges[][] = [[0, 3, 6], [1, 0, 4], [1, 2, 6], [3, 1, 2]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/705719/Web/Other/blobid2_1787650381.png" width="203" height="178"><strong>
Output: </strong>false<strong>
Explanation: </strong>Cycle 1 -&gt; 0 -&gt; 3 -&gt; 1 has total weight 6 + 4 + 2 = 12, which is positive, so no negative weight cycle exists.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/705719/Web/Other/blobid3_1787650457.png" width="188" height="165"><br></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>V = 4, E = 4, edges[][] = [[1, 0, 4], [3, 1, -2], [1, 2, -6], [2, 3, 5]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/705719/Web/Other/blobid4_1787650481.png" width="195" height="171"><strong>
Output: </strong>true<strong>
Explanation: </strong>There is a cycle 1 -&gt; 2 -&gt; 3 -&gt; 1 with total weight -3, which is negative, so a negative weight cycle exists.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/705719/Web/Other/blobid5_1787650506.png" width="184" height="161"><br></span></pre>
