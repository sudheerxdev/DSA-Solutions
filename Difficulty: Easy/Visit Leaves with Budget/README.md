<h2><a href="https://www.geeksforgeeks.org/problems/leaf-under-budget/1">Visit Leaves with Budget</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="PDq2pG_selectionAnchorContainer" data-start="362" data-end="527"><span style="font-size: 14pt;">Given&nbsp;a binary tree and an integer <strong>k</strong>, where you start from the root at level 1. The cost of visiting a leaf node is equal to the level of that leaf node. </span><span style="font-size: 14pt;">You can visit any number of leaf nodes, but the total cost of visiting them must not exceed k. </span></p><p class="PDq2pG_selectionAnchorContainer" data-start="362" data-end="527"><span style="font-size: 14pt;">Return the maximum number of leaf nodes that can be visited within the given budget.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input: </strong>root[] = [10, 8, 2, 3, N, 3, 6, N, N, N, 4], k = 8<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/926895/Web/Other/blobid1_1776856866.png" width="205" height="185">
<strong>Output: </strong>2
<strong>Explanation:</strong>
Cost For visiting Leaf Node 3: 3
Cost For visiting Leaf Node 4: 4
Cost For visiting Leaf Node 6: 3
To maximize the number of visited leaves, choose the two cheapest leaves: Cost = 3 + 3 = 6 ≤ 8. <br>Thus, the maximum number of leaf nodes that can be visited is 2.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>root[] = [1, 2, 3, 4, 5, 6, 7], k = 5<strong><br></strong><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/926895/Web/Other/blobid2_1776856916.png" width="208" height="138"></span><br><span style="font-size: 14pt;"><strong>Output: </strong>1<br><strong>Explanation:</strong> The leaf nodes are 4, 5, 6 and 7, and all are at level 3. Therefore, visiting each leaf costs 3. With a budget of 5, we can visit only one leaf because: 3 ≤ 5, but 3 + 3 &gt; 5. Thus, the maximum number of leaf nodes that can be visited is 1.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>root[] = [1], k = 1         </span><br><span style="font-size: 14pt;"><strong>Output: </strong>1<br><strong><strong>Explanation: </strong></strong>The root node is also a leaf node and is at level 1. Therefore, its visiting cost is 1. Thus, the maximum number of leaf nodes that can be visited is 1.</span></pre></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Oracle</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Tree</code>&nbsp;
