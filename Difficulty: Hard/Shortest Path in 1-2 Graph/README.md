<h2><a href="https://www.geeksforgeeks.org/problems/level-of-nodes1147/1">Shortest Path in 1-2 Graph</a></h2><h3>Difficulty Level : Difficulty: Hard</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;"><span style="font-size: 18px;">Given a<strong> </strong></span><span style="font-size: 18px;">weighted undirected graph</span><span style="font-size: 18px;"> with</span><strong style="font-size: 18px;"> V</strong><span style="font-size: 18px;"> vertices numbered from </span><strong style="font-size: 18px;">0</strong><span style="font-size: 18px;"> to </span><strong style="font-size: 18px;">V - 1</strong><span style="font-size: 18px;">, represented by an array edges, where <strong>edges[i] = [u<sub>i</sub>, v<sub>i</sub>, w<sub>i</sub>] </strong>indicates that there is an edge between vertices u<sub>i</sub> and v<sub>i</sub> with a weight of w<sub>i</sub>. (w<sub>i</sub> can only be </span><span style="font-size: 18px;">1</span><span style="font-size: 18px;"> or </span><span style="font-size: 18px;">2</span><span style="font-size: 18px;">), and two vertices </span><strong style="font-size: 18px;">src</strong><span style="font-size: 18px;"> and </span><strong style="font-size: 18px;">dest</strong><span style="font-size: 18px;">, find the<strong> </strong></span><span style="font-size: 18px;">shortest distance</span><span style="font-size: 18px;"> from src to dest.</span></span></p>
<p><span style="font-size: 18px;">The shortest distance is defined as the minimum total weight required to reach dest starting from src.</span></p>
<p><span style="font-size: 18px;">Return the shortest distance from src to dest. If dest is not reachable from src, return -1.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>V = 4, edges[][] = [[0, 1, 1], [0, 2, 2], [2, 3, 1], [1, 2, 1], [1, 3, 2]], src = 0, dest = 3
</span><span style="font-size: 18px;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929545/Web/Other/blobid0_1781262007.png" width="274" height="223"><br><strong>Output:</strong> 3
<strong>Explanation</strong>: One of the shortest paths from vertex 0 to vertex 3 is 0 -&gt; 1 -&gt; 3 with a total weight of 1 + 2 = 3.
Another shortest path is 0 -&gt; 2 -&gt; 3 with a total weight of 2 + 1 = 3.
Hence, the shortest distance from 0 to 3 is 3. </span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>V = 5, edges[][] = [[0, 1, 1], [0, 2, 2], [1, 2, 1], [3, 4, 2]], src = 1, dest = 3
</span><span style="font-size: 18px;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929545/Web/Other/blobid1_1781262339.png" width="291" height="150"><br> <strong>Output:</strong> -1
<strong>Explanation</strong>: There is no path from vertex 1 to vertex 3, so the answer is -1.<strong> </strong></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>V = 5, edges[][] = [[1, 0, 1], [0, 3, 2], [1, 3, 1], [1, 2, 2], [2, 3, 2], [3, 4, 1], [2, 4, 1]], src = 1, dest = 4
</span><span style="font-size: 18px;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929545/Web/Other/blobid2_1781262429.png" width="252" height="205"><br><strong>Output:</strong> 2
<strong>Explanation</strong>: The shortest path from vertex 1 to vertex 4 is 1 -&gt; 3 -&gt; 4 with a total weight of 1 + 1 = 2.
Hence, the shortest distance from 1 to 4 is 2.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>2 ≤ V ≤ 10<sup>5<br></sup>1 ≤ edges.size() ≤ min(2*10<sup>5</sup>,&nbsp; V*(V-1)/2)<br>0&nbsp;</span><span style="font-size: 18px;">≤ edges[i][0], edges[i][1]&nbsp;</span><span style="font-size: 18px;">≤ V-1<br>edges[i][0] != edges[i][1]<br>1&nbsp;</span><span style="font-size: 18px;">≤ </span><span style="font-size: 18px;">edges[i][1]&nbsp;</span><span style="font-size: 18px;">≤ 2</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Graph</code>&nbsp;<code>BFS</code>&nbsp;
