# [Lexicographically Smallest Rotation](https://www.geeksforgeeks.org/problems/lexicographically-smallest-string--151951/1)
## Hard
Given a string s, find the&nbsp;lexicographically smallest string after rotating the string left any number of times including 0.Example:Input:&nbsp;s = "abcd"Output: "abcd"Explanation: String after each rotation are "abcd", "bcda", "cdab", "dabc" and so on. Lexicographically smallest among them is "abcd".Input: s = "baca"
Output: "abac"
Explanation: Strings after each rotation are "baca", "acab", "caba", "abac" and so on. Lexicographically smallest among them is "abac".
